# PyPi-SCADA Archive

This directory preserves historical project material that is no longer part of
the active simulator -> injector -> analyzer pipeline.

Contents include old audit reports, agent notes, completed checklists, course
status deliverables, superseded injector tooling, and project-management helper
scripts. These files are kept for provenance and thesis evidence only; do not use
them as active setup or operating instructions.

For current usage, start with `README.md`, `docs/USAGE.md`, and
`docs/ops/DEPLOYMENT_MANIFEST.md`.
